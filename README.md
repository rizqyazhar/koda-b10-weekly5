# Web Design Slicing Warga Report

A platform for reporting community issues and connecting citizens with local policymakers to drive meaningful action and positive change.

## Tech Stack

The technologies used in this project:

- [React](https://react.dev/) – JavaScript library for building user interfaces.
- [Vite](https://vite.dev/) – Fast frontend build tool and development server.
- [React Router](https://reactrouter.com/) – Library for handling client-side routing and navigation.
- [Tailwind CSS](https://tailwindcss.com/) – Utility-first CSS framework for styling.
- [React Hook Form](https://react-hook-form.com/) – Performant and flexible library for managing form state and handling form submissions.
- [Yup](https://www.npmjs.com/package/yup) – JavaScript schema validation library for defining and validating form data.
- [Hookform Resolvers](https://www.npmjs.com/package/@hookform/resolvers) – Integrates Yup validation schemas with React Hook Form to provide seamless form validation.
